Voice Agent is a production-ready FastAPI service that combines Bolna.ai telephony, Google Gemini 2.5 Flash LLM capabilities, and a pgvector-powered RAG pipeline into a single deployable backend. Whether you are building an AI call centre agent, a document Q&A interface, or a product-search voice tool, Voice Agent provides the REST API layer you need.

## What Voice Agent does

Voice Agent exposes a unified REST API across five functional domains:

<CardGroup cols={2}>
  <Card title="Outbound Voice Calls" icon="phone" href="/guides/voice-agent-setup">
    Trigger Bolna.ai voice agents to call any phone number. Register webhook tools so the LLM can query your knowledge base mid-call.
  </Card>
  <Card title="Streaming AI Chat" icon="message-bot" href="/api/chat/conversation">
    Server-Sent Events streaming chat powered by Gemini 2.5 Flash. Each message is persisted and embedded for future retrieval.
  </Card>
  <Card title="Document Ingestion & RAG" icon="file-magnifying-glass" href="/guides/document-ingestion">
    Upload PDF, DOCX, XLSX, CSV, and images. Content is extracted, embedded with pgvector, and surfaced via hybrid semantic search.
  </Card>
  <Card title="User & Role Management" icon="users" href="/concepts/authentication">
    JWT-based auth with role-based access control, per-user token limits, and email-based password reset.
  </Card>
</CardGroup>

## Get started in three steps

<Steps>
  <Step title="Install dependencies and configure environment">
    Clone the repo, create a `.env` file with your PostgreSQL, Google API, and Bolna credentials, then install Python dependencies.
    ```bash
    pip install -r requirements.txt
    cp .env.example .env   # fill in your values
    ```
  </Step>
  <Step title="Run database migrations">
    Apply the Alembic schema migrations to your PostgreSQL database.
    ```bash
    make upgrade
    ```
  </Step>
  <Step title="Start the server">
    Launch the Uvicorn server. The interactive API docs are available at `http://localhost:8081/docs`.
    ```bash
    python startup.py
    ```
  </Step>
</Steps>

<Note>
  Voice Agent requires PostgreSQL with the **pgvector** extension installed. See [Configuration](/configuration) for the full list of required environment variables.
</Note>
