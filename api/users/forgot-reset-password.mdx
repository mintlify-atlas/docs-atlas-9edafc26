---
title: "POST /api/forgotPassword & resetPassword — password recovery"
sidebarTitle: "Forgot Password"
description: "Two-step public password recovery: forgotPassword returns a reset link for the user's email; resetPassword applies the new password to their account."
---

Password recovery in Voice Agent is a two-step, unauthenticated flow. First, call `forgotPassword` with the user's email address — the server verifies the account exists and returns a redirect URL (in production this URL would be emailed to the user). Second, once the user has navigated to that URL and chosen a new password, call `resetPassword` with the same email address and the new password to apply the change. Neither endpoint requires a bearer token, making them safe to call before the user can authenticate.

---

## POST /api/forgotPassword

Initiates the password reset process. The server looks up the account by email and, if found, returns a redirect URL for the reset page. In a production deployment this URL is delivered to the user's inbox; the current implementation returns it directly in the response payload.

```http
POST /api/forgotPassword
```

### Authentication

<Note>
  This is a **public endpoint** — no `Authorization` header is required. It is designed to be called by users who cannot currently log in.
</Note>

### Request Body

<ParamField body="data" type="object" required>
  The `DataRequest` wrapper object.

  <Expandable title="data fields">
    <ParamField body="emailId" type="string" required>
      The email address of the account for which a password reset is being requested. Must be a valid email format and must correspond to an existing, non-deleted user account.
    </ParamField>
  </Expandable>
</ParamField>

### Response

```json
{
  "dataResponse": {
    "returnCode": 0,
    "responseDateTime": "2024-01-15T10:30:00",
    "description": "Password reset initiated. Check your email for instructions."
  },
  "data": {
    "redirect_url": "https://example.com/reset_password_dummy"
  }
}
```

<ResponseField name="dataResponse" type="object">
  <Expandable title="dataResponse fields">
    <ResponseField name="returnCode" type="integer">
      `0` on success. See [Error Codes](#error-codes-forgotpassword) for failure values.
    </ResponseField>

    <ResponseField name="responseDateTime" type="string (ISO 8601)">
      Server timestamp of when the response was generated.
    </ResponseField>

    <ResponseField name="description" type="string">
      `"Password reset initiated. Check your email for instructions."` on success.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="data" type="object">
  Contains the redirect information for the password reset page.

  <Expandable title="data fields">
    <ResponseField name="redirect_url" type="string">
      The URL the user should visit to complete the password reset. In production this URL is sent via email; in the current implementation it is returned directly in the response.
    </ResponseField>
  </Expandable>
</ResponseField>

### Example

```bash
curl -X POST https://your-api-host/api/forgotPassword \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "emailId": "alice@example.com"
    }
  }'
```

```json
{
  "dataResponse": {
    "returnCode": 0,
    "responseDateTime": "2024-01-15T10:30:00.123456",
    "description": "Password reset initiated. Check your email for instructions."
  },
  "data": {
    "redirect_url": "https://example.com/reset_password_dummy"
  }
}
```

### Error Codes — forgotPassword

| `returnCode` / HTTP status | Name        | Description                                                                                 |
|----------------------------|-------------|---------------------------------------------------------------------------------------------|
| `0` / `200`                | `SUCCESS`   | Account found; redirect URL returned in `data`.                                             |
| `404 Not Found` (HTTP)     | —           | No active user account with the given email address exists. No `APIResponse` body returned. |

## POST /api/resetPassword

Applies a new password to the account identified by the given email address. Call this endpoint after the user has followed the reset link obtained from `forgotPassword`. The password is stored as provided.

```http
POST /api/resetPassword
```

### Authentication

<Note>
  This is a **public endpoint** — no `Authorization` header is required. It is designed to complete the password recovery flow before the user can log in.
</Note>

### Request Body

<ParamField body="data" type="object" required>
  The `DataRequest` wrapper object.

  <Expandable title="data fields">
    <ParamField body="emailId" type="string" required>
      The email address of the account whose password is being reset. Must match an existing, non-deleted user account.
    </ParamField>

    <ParamField body="newPassword" type="string" required>
      The new password to set for the account. Stored as-is; choose a strong password. After a successful reset, the user can log in via [Verify Password](/api/users/verify-password) using this new password.
    </ParamField>
  </Expandable>
</ParamField>

### Response

```json
{
  "dataResponse": {
    "returnCode": 0,
    "responseDateTime": "2024-01-15T10:30:00",
    "description": "Password has been reset successfully."
  },
  "data": null
}
```

<ResponseField name="dataResponse" type="object">
  <Expandable title="dataResponse fields">
    <ResponseField name="returnCode" type="integer">
      `0` on success. See [Error Codes](#error-codes-resetpassword) for failure values.
    </ResponseField>

    <ResponseField name="responseDateTime" type="string (ISO 8601)">
      Server timestamp of when the response was generated.
    </ResponseField>

    <ResponseField name="description" type="string">
      `"Password has been reset successfully."` on success.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="data" type="null">
  Always `null` for this endpoint. The outcome is communicated through `returnCode` and `description`.
</ResponseField>

### Example

```bash
curl -X POST https://your-api-host/api/resetPassword \
  -H "Content-Type: application/json" \
  -d '{
    "data": {
      "emailId": "alice@example.com",
      "newPassword": "newS3cur3P@ss!"
    }
  }'
```

```json
{
  "dataResponse": {
    "returnCode": 0,
    "responseDateTime": "2024-01-15T10:30:00.123456",
    "description": "Password has been reset successfully."
  },
  "data": null
}
```

After a successful reset, the user can immediately log in with the new password via [Verify Password](/api/users/verify-password).

### Error Codes — resetPassword

| `returnCode` / HTTP status | Name        | Description                                                                                 |
|----------------------------|-------------|---------------------------------------------------------------------------------------------|
| `0` / `200`                | `SUCCESS`   | Password updated; user can now authenticate with the new credentials.                       |
| `404 Not Found` (HTTP)     | —           | No active user account with the given email address exists. No `APIResponse` body returned. |
